## 运行与发布门槛

```bash
python scripts/self_test.py
python scripts/test_regressions.py
python scripts/test_powerpoint.py
python scripts/test_desktop.py --output-dir /absolute/new-test-directory
```

CI 在 macOS / Windows 执行 Python 单元与回归测试；没有 TeX 时明确跳过两个引擎集成测试，没有 Illustrator 的托管环境不运行桌面验收。新增工作流不等于已经通过远端 CI，以对应提交的实际 Actions 结果为准。

桌面验收目录输出 `acceptance.json`、阶段日志、AI/PNG/Master SVG、公式清单与源码、原生对象审计和各类差异图。结构检查与人工公式/原图复核分开记录，默认不会把未检查的语义标为通过。

## 2026-09-17 同图复杂插画复测

使用心肌梗死机制参考图，在 Mac Illustrator 29.5.1 对20个复杂插画组逐组检查并做本图专用修复；不是通用自动修复算法，也未调用外部识别服务。

- 细胞膜/核的连续描边、NP圆环、血管壁及错误背景孔洞得到修复；健康心肌从7个粘连同色区域恢复为14个独立细胞。
- 最终1971×1706，37个TextFrame、3条TeX公式、1394条路径、20个插画组，零位图/置入对象；37个文字的内容、字体和字号保持。
- 57批实机播放：首批为80条基础/公式路径及37个文字，之后最多24项复杂对象操作/批；实际点击单步、暂停、继续，并观察首批与第48、50批实际画布；暂停64.7秒游标稳定，最终DONE。
