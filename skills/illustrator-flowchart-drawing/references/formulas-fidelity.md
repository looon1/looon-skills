# Illustrator 公式排版与高保真验收

本要求用于 Illustrator 分支。默认普通文字与数学内容统一真实粗体，变量同时保持数学斜体；这是用户明确指定的字重调整，不能顺带改动原图内容、布局、线宽或配色。用户在后续任务明确指定其他字重时，以该任务为准。

## 先建立可对照的清单

- 记录参考图原始宽高、画板比例、坐标单位及每个对象的边界、连线端点、箭头方向、描边、颜色、层级。独立图标可分组，不能把整图合并成一个不可分拆对象。
- 将普通文字与公式分开登记。每处公式分配唯一 ID（如 `F001`）；重复出现的公式仍记录各自位置，可共用同一源码。
- 逐字核对公式中的变量、数字、正负号、乘除、括号、希腊字母及其变体、上下标归属、分子分母、求和上下限、帽符号覆盖范围和运算符。识别不清的位置单独列出，不能猜测或改成数学上“更合理”的内容。
- 不把 `x²`、`x₂` 等 Unicode 近似字符当作结构化脚标，不用普通文本框分别摆放数字、分子、分母或帽符号来拼公式。普通化学式若包含上下标，也按结构化数学/化学排版处理。

## 正规排版与真实字形

1. 使用能够输出矢量的正规数学排版引擎，以完整 LaTeX、MathML 或等效结构化源码生成公式。上下标、分式、求和上下限和重音符号必须由引擎排版，不能靠空格、换行或人工移动单独文本框模拟。
2. 核对实际使用的普通粗体、数学粗体与数学粗斜体字形。字体名称或设置了 `font-weight:bold` 不足以证明有真实粗体；要检查解析到的字体、字形及替换记录。变量使用数学粗斜体，按原图语义保持数字、函数名、运算符等的直立/斜体区分，正负号和希腊字母也须核对字重。
3. 禁止重复叠放文字、重复绘制同一轮廓、增加文字描边、伪粗体或几何倾斜模拟粗斜体。字形缺失时换用已核验的匹配字体，不能用近似字符补位。
4. 按原图核对公式的正文、脚标与上下限字号，基线、分式横线、重音位置及字间距。对整条公式只做等比缩放与定位；不能分别拉伸字形或压扁公式来塞入目标边框。需要调整时修改排版源码或字号后重新生成。
5. 在 Illustrator 中验证公式能否稳定修改、保存和重新打开。不能稳定编辑时，将**正规排版结果**转换为清晰矢量轮廓；保留字形孔洞、笔画和分式横线，按公式 ID 分组。不得描摹公式截图或将公式栅格化。普通文字仍保留原生文本框。

## 与现有脚本衔接

`prepare_job.py` 的 `labels` 只用于普通单行文本；`native.jsx` 不包含数学排版器，也不会自动导入公式、生成公式清单或最终 Master SVG。仅把 LaTeX 写入 `text` 字段不会得到数学公式。公式任务需要 agent 在当前环境完成排版、矢量导入及对应验证，不得虚报现有脚本已经支持这些功能。

- 从 `labels` 中排除数学公式，另写 `formulas.json`。如果没有普通文字，现有脚本的非空文字检查也需要针对该任务适配；不能添加虚假文本对象来通过检查。
- 在结构重建前登记旧公式所在范围与相邻图形；在最终整合时精确清理旧公式轮廓，不得破坏其下方背景、附近连线或插图。`structure` 会重组背景及复杂插图，最终公式应在结构整理后导入，并核对被替换的旧公式没有残留。
- 将公式放在独立命名图层/分组，保留与原图一致的遮挡关系，不能因为单独分层就把全部公式无条件置顶。普通文字、公式与复杂插图分别统计。
- 公式是完整的静态结构，首批与普通文字、框线、箭头、虚线一起出现；转为轮廓也不能放入 `02 Illustrations` 逐字符播放。现有实时脚本仅支持其声明的对象类型，公式导入产生的复合路径、剪切或插件对象需要适配。适配时保留孔洞、填充规则、层级和语义分组，先验证小范围公式再播放整图；不能静默丢对象、填死孔洞或改用位图。
- `verifyText()` 的普通文本计数通过，不代表公式通过。公式必须逐项对照源码、原图和保存回读结果。未具备所需字体、引擎或应用接口时，明确记录尚未完成的项目。

## 文件交付

| 文件 | 要求 |
| --- | --- |
| `figure.ai` | 完整主图；普通文字可编辑，所有框体、节点、线条、符号和图标均为独立矢量对象；说明每条公式是稳定可编辑结构还是轮廓。 |
| `preview.png` | 从最终主图导出，裁切到同一画板；保持原始宽高比、内容范围和方向，不拉伸、不意外加边或裁切。 |
| `master.svg` | 从含最终公式的完整主图导出；`viewBox` 与画板范围、宽高比一致，保留对象、图标和公式分组。普通文字保持文本元素；外观依赖的字体和所需环境必须记录，不以轮廓替换普通文字。不能以一张嵌入或链接位图充当 Master SVG。 |
| `formulas.json` | 逐项登记公式 ID、位置与坐标单位、完整结构化源码、源码文件路径、字体及字重、字号和排版引擎/版本、导入对象名称、编辑方式、逐项核验状态及差异。无公式时交付空清单并注明。 |
| 公式源码文件 | 保留实际使用的 `.tex`、`.mml` 等源文件及生成所需的导言、宏定义、字体设置和命令。不能只留公式截图或不完整的表达式字符串。 |

脚本早期导出的 `figure.svg` 不自动等于最终 `master.svg`。若公式导入或修正了任一对象，必须从最终主图重新导出 AI、PNG 和 Master SVG；不要仅重命名旧导出来冒充完成。重新打开 Master SVG 检查缺字、字体替换、分组、字形孔洞、连线与画板范围。

## 最终检查

先以整图检查画布比例、布局、坐标、尺寸、层级、颜色和连线关系，再在约 400%–800% 放大下逐字检查错字、乱码、缺笔画、真假粗体、数学斜体、脚标与公式错位、重复对象和线条遮挡。删除测量用文字副本或轮廓副本，确认没有通过重复叠放加粗。

保存并重新打开 AI 与 Master SVG，再导出 PNG 对照原图及当前最终稿。分别记录“对原图的保真差异”和“保存回读/导出是否一致”，不能互相替代。可编辑公式、轮廓公式和普通文字分别报告；未检查的公式标记未验证。

本参考文件整合的是制图要求与执行约束，不代表已经在本机或 Windows 验证了新的数学排版引擎。
