# 部件编辑与局部验收

用于现有图的改色、移动、局部轮廓修复或连线调整。沿用已有 AI、稳定对象名称、清单和原图，只读与当前修改相关的规则。

## 编辑单元

科学归属、遮挡顺序、一起操作的成员分别判断。细胞膜、胞质、核、颗粒和阴影可以属于同一细胞；标签是否随动取决于标注用途，公共图例不自动加入。前后穿插的部件不为方便分组而改变叠放。

- 先确定要改的对象及随动成员；完整部件可用具名组，跨层对象用任务内的成员记录和脚本联动，保留原图层关系。
- 给参与修改的对象稳定、唯一名称，保留原有名称映射。文字继续是 TextFrame，公式继续用正规排版与源码；不能为了同组而转曲文字。
- 新建语义组时，在任务副本中移动整组或单改一个子部件，检查膜、阴影、颗粒是否遗留，其他对象是否误变。只测试有联动风险的部件；恢复后再交付。
- 查看移动后露出的区域。旧轮廓、缺失底色、被遮挡内容不能靠白色盖片修补；只依据参考可见内容和已确认资料重建，不能推测科学细节。

## 连线端点与接合

移动带连线的对象前，在现有任务记录中标明：连线名称、起止对象、各自接点、随动标签及允许改变的范围。接点依据科学关系确定，不能自动吸附到最近的对象。

这是任务侧编辑约定，不是新增的 manifest 字段，也不是 Illustrator 自动吸附功能。沿用原生 JSX 在副本中移动对象并更新相关连线；若修改清单，写回现有 `nativeLayout.elements[].points` 等受支持字段。不能写入未实现的绑定字段后声称程序已处理。

- 接点随所属对象的实际变换更新，统一坐标系，避免将图片左上角坐标与 Illustrator 坐标混用。核对箭头朝向、端点间隙和标签位置。
- 保留原图曲线走向及控制柄；仅更新必要端点和相邻控制柄。曲线需要较大调整时对照原图复核，不能用通用直线/折线自动布线改掉参考布局。
- 真正接合的外形共享接口位置；只在原图应平滑的位置保持切向。关节、尖端、分离间隙和孔洞不能统一平滑或填满。
- 交叉不代表相连，遮挡不代表断裂。移动后检查前后层级、线条遮挡和连接对象是否仍正确。

## 两项验收

修改前确定最小允许范围，包含确实需要随动的线端、文字及共享资源；不能为让检查通过而事后放大允许范围。

1. **目标改善**：原图、修前、修后按相同区域和倍率比较；写清实际改善的位置和剩余缺陷。复杂轮廓沿用 [逐组轮廓验收](illustration-contours.md)，不能用路径数量或文件相等代替观察。
2. **区域保护**：对比未授权区域的几何、文字、层级、透明度和共享资源；父级变换也属于保护范围。保存重开检查继续保留，但不能代替这项检查。

两项分别记录通过、失败或未验证。未修改目标也可能通过保护检查；保护通过但目标无改善时不采用候选稿。

SVG 源码需要确定性范围证据时，可使用本 Skill 的独立实现：

```bash
python scripts/check_svg_edit_scope.py before.svg after.svg --allow cell-ros
```

仅用于具有稳定、唯一 ID 的两份自包含 SVG。允许 ID 应选目标部件，不选整张画布；多个必要范围重复 `--allow`。检查保留元素顺序、属性和文本，对允许范围外的变化报错。涉及样式表、共享引用或动画时保守返回需复核；不能关闭检查来掩盖依赖。

此工具不比较 AI、不验证成员完整性或视觉效果、不证明 SVG 安全。Illustrator 重新导出的 ID 或序列化发生变化时，不能据此认定画面变坏，也不能自动忽略差异；使用真实对象名称回读、共享资源核对和相同画幅的预览确认。没有稳定 ID 的文档直接做原生对象与视觉检查，不为普通小修改强行改写全图。

## 积累可复用修复

遇到重复缺陷时，在当前任务报告保留最小修前/修后局部和处理方法，例如轮廓重复、胞质被核切空、细丝断裂、相邻组织黏连。区分候选、失败、已验证，注明对象类型与实际验证范围；单个细胞修复成功不推广为所有插画通用算法。不将用户图片自动纳入公共素材库。
