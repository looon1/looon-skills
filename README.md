# looon-skills

Personal reusable skills for Codex.

## Skills

- [`looon-remotion-skills`](skills/looon-remotion-skills/SKILL.md) — Build configurable Remotion explainer animations with replaceable backgrounds and brand colors.
- [`paper2ppt`](skills/paper2ppt/SKILL.md) — Turn scientific papers into panel-complete, Results-led Chinese journal-club presentations with validated crops, selectable academic styles, and speaker notes.
- [`illustrator-flowchart-drawing`](skills/illustrator-flowchart-drawing/README.md) — 将参考图重建为可编辑 AI；文字保留原生文本框，支持 Illustrator 逐步绘制与 Windows PowerShell 入口。
